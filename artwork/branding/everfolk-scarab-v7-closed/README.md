# Everfolk — crowned scarab at rest

The scarab rests with its paired golden wing cases closed over the body. The crowned head, jade thorax, connected core and three closely spaced leg pairs use the geometry of the previous colour revision. The emblem has a compact upright silhouette.

Open `review/Everfolk-Crowned-Scarab-Closed.png` for the main logo proof. `review/Dawnwing-Identity-Proof.png` shows the standalone emblem, combined name treatment, independent wordmark and icon sizes. Both layouts include editable VectorCraft documents and SVGs.

`masters/Everfolk-Crowned-Scarab-Closed.vectorcraft` contains eight transparent artboards: primary and compact colour emblems, stacked and horizontal signatures for light/dark surfaces, and the independent name in ink/cream. `svg/` and `png/` hold eight production variants, with additional compact icon PNGs at 16, 24, 32, 48, 64, 128 and 256 px.

All production artwork is editable native vector geometry. Negative spaces are transparent. The master was saved, closed and reopened with eight artboards and zero raster images; export warnings were empty. Both proof layouts were rendered and visually checked.

The original paths are in `source/body.cjs`. Rebuild on this installation with `node source/build.cjs`, using the installed ArtCraft MCP helper and VectorCraft CLI. The helper closes its task-owned headless process when finished.

The scarab and full Everfolk. name each remain independently usable. Lettering is the approved clean outlined Printed Folktale artwork: Eczar 600, −0.025 em tracking and the clay period.
