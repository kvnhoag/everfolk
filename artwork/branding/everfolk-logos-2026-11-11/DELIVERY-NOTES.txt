EDITABLE MASTERS
masters/ contains 20 individual .vectorcraft files. Each has four artboards:
1. Primary logo with live editable wordmark and motto, 720 x 340.
2. Colour device, 160 x 160.
3. One-colour device, 160 x 160.
4. Reverse logo with live editable wordmark and motto, 720 x 340.
Named layers separate each treatment; devices contain editable vector paths.
Open a master with VectorCraft to edit geometry, colour or type.

EXPORTS
svg/ contains 80 transparent SVG files: primary, icon, mono and reverse.
SVG lettering is converted to outlines so it displays without installed fonts.
Reverse files use light lettering and should be placed on a dark teal ground.
png/ contains 40 transparent PNG files: 1440 x 680 primary logos and
320 x 320 colour devices. The black area some viewers show is transparency.

TYPE
The current Courier New Bold brand treatment is retained in several options.
Source Serif 4 Regular and Georgia Regular/Bold explore literary alternatives.
Inter Regular supports the motto. Native files use installed fonts; SVGs
do not require those fonts. Font files are not redistributed in this package.
