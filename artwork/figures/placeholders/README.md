# Temporary figure portraits

These seven images are generic role stand-ins for the card UI. They are **not final illustrations, historical likenesses or newly reconstructed clothing/equipment**. Keep the visible **Placeholder art** label until replacement art is approved.

Each output is an exact byte copy of an existing Everfolk character-creator `front-3x.png` export, at 192 × 288 pixels. The underlying logical portrait grid is 64 × 96. The seven distinct role families make the temporary roster readable while keeping the existing game's visual language.

## Provenance and checks

[manifest.json](manifest.json) records each source, editable `front.ora` master, output URL, dimensions and SHA-256 digest. Source/output bytes match. PNG signatures, chunk CRCs, compressed image data and dimensions were checked.

The portraits were inspected with their eyes, frontal gaze, silhouettes and role props visible. The UI supplies the card frame, background, type, rarity treatment and temporary-art label separately.

This reuse pass performs no image generation, raster edits, ArtCraft brushwork or PixelOE conversion. It preserves the existing exported pixel grid and transparency exactly; no new historical-evidence or manual-painting claim is made. Later final illustration work should follow the full reference-led Everfolk asset workflow.
